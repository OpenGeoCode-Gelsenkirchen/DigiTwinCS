    Overview

    /dist

    This folder is populated with the built files generated by npx vite build --mode ENVIRONMENT_NAME

    /docs

    This folder contains the generated documentation files from the folder /documents and the source code. Documentation is built with npx typedoc.

    /documents

    User documentation via .md files. Gets built into /documents

    /env

    Folder containing environment files used to built for different environments (external, internal, debug).

    /examples

    Example config and locales files.

    /node_modules

    All packages which are downloaded by npm are put here.

    /notes

    Notes, ideas, etc. for developing this project.

    /public

    Contains all static assets like images, configuration and locales, as well as jquery-ui (for legacy reasons).

    /src

    Entry point of the project is init.js. This folder primarily contains legacy source files and setup files which tend to be more frontend-y.

    Import files

    init.js
    loadLayer.js
    localdata.js
    main.js

    /src/@types

    Additional types for better static analysis.

    /src/Components

    All Custom Web Components are listet here. A Custom Web Component is split into html, css and js/ts and built by vite.

    /src/Core

    Core is structured much more strictly and can be seen more backend-y.

    /src/Core/Annotations

    Code for loading annotation data and clustering annotations.

    /src/Core/Commands

    Only contains abstract Command class. Was created for testing purposes.

    /src/Core/Drawing

    Measurements are composites that use drawings. This folder defines all drawing types (including an abstract base class).

    /src/Core/Loader

    Implements PNG and GeoTIFF loader classes. Loading logic from Loader.js should be refactored and put here.

    /src/Core/Measurement

    All measurement functionality is located here and inherits from the abstract base class Measurement.js.

    /src/Core/UrbanPulse

    Implements querying and processing sensor data. sensor-polling.ts is application code and UrbanPulseConnector static business logic.

    /src/Core/Writer

    Implements export functionality for DXF and geojson.

    /src/States

    This project uses a custom state engine where the application can apply and remove a state objects to switch behavior.

    /src/viewshed

    Viewshed functionality. ShadowMap.js and ShadowMapShader.js are derived from Cesium.js and were modified afterwards.

    /style

    Most of the css styling happens here. You can use theme.module.css to theme the application easily.

    /.index.html

    Entry point

    /.prettierc

    Configuration file for prettier.

    /.eslint.config.js

    Configuration file for eslint.

    /README.md

    Github README.

    /tsconfig.json

    Typescript configuration.

    /vite.config.js

    Configuration of vite. Defines the build process as files have to be copied during build.

    /vite.out.config.js

    Custom config for docs using port 5174.

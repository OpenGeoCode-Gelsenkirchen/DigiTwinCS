    Class default

    Use Viewer#shadowMap to get the scene's shadow map. Do not construct this directly.

    The normalOffset bias pushes the shadows forward slightly, and may be disabled for applications that require ultra precise shadows.

    Alias

    ShadowMap

    Internal Constructor

    Private Param

    options An object containing the following properties:

    Private Param

    options.context The context

    Private Param

    options.lightCamera A camera representing the light source.

    Private Param

    [options.enabled=true] Whether the shadow map is enabled.

    Private Param

    [options.isPointLight=false] Whether the light source is a point light. Point light shadows do not use cascades.

    Private Param

    [options.pointLightRadius=100.0] Radius of the point light.

    Private Param

    [options.cascadesEnabled=true] Use multiple shadow maps to cover different partitions of the view frustum.

    Private Param

    [options.numberOfCascades=4] The number of cascades to use for the shadow map. Supported values are one and four.

    Private Param

    [options.maximumDistance=5000.0] The maximum distance used for generating cascaded shadows. Lower values improve shadow quality.

    Private Param

    [options.size=2048] The width and height, in pixels, of each shadow map.

    Private Param

    [options.softShadows=false] Whether percentage-closer-filtering is enabled for producing softer shadows.

    Private Param

    [options.darkness=0.3] The shadow darkness.

    Private Param

    [options.normalOffset=true] Whether a normal bias is applied to shadows.

    Private Param

    [options.fadingEnabled=true] Whether shadows start to fade out once the light gets closer to the horizon.

    Exception

    Only one or four cascades are supported.

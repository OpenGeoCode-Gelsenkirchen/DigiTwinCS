    Class WaterPrimitive

    Custom Cesium water-surface primitive rendered with a normal-map-based GLSL material.

    Remarks

    This class follows Cesium's custom primitive contract:

    • Cesium invokes update during rendering.
    • The primitive lazily loads its normal map.
    • Geometry is baked and combined into a GPU vertex array.
    • A custom shader program and draw command are created once.
    • The cached draw command is submitted on subsequent frames.

    The primitive uses low-level Cesium renderer APIs including DrawCommand, ShaderProgram, RenderState, Texture, and VertexArray. These APIs are not part of Cesium's most stable public surface and should be retested after Cesium upgrades.

    Example

    const water = WaterPrimitive.fromRectangle({
      rectangle: Rectangle.fromDegrees(6.9, 51.4, 7.0, 51.5),
      height: 10,
      options: {
        ...WaterPrimitive.DefaultOptions(),
        show: true,
        baseWaterColor: new Color(0.13, 0.34, 0.48, 0.75),
      },
    });

    viewer.scene.primitives.add(water);

    • _combineGeometries(geometries: Geometry[]): Geometry

      Merges baked geometries into one indexed triangle geometry.

      Parameters

      • geometries: Geometry[]

        Already baked Cesium geometries with position, normal, texture-coordinate, and index attributes.

      Returns Geometry

      Combined triangle geometry.

      Throws

      Thrown when a supplied geometry does not provide the required attributes or indices.

      Remarks

      Vertex indices from each geometry are offset by the total number of vertices preceding it in the combined buffers.

      The method uses Uint16Array for indices. It can represent at most 65,536 vertices. Use Uint32Array when combined geometry can exceed that count and the target WebGL capabilities support it.

      Creates a water primitive from polygon entities in a Cesium data source.

        Data source whose polygon entities define water areas.

        Optional water shader overrides.

      Returns WaterPrimitive

      Water primitive containing one geometry instance per valid polygon.

      Remarks

      Only entities with polygon graphics are used. Polygon hierarchy is evaluated at the current Cesium time, and geometry is configured with perPositionHeight: true to preserve source vertex heights.

      Entities with an unresolved polygon hierarchy should be skipped explicitly if dynamic or incomplete polygon properties are expected.
